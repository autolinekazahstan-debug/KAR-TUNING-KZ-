# KarTuningKZ

Проект сайта KarTuningKZ — современная площадка для автомобильного тюнинга и автосервисных услуг в Казахстане.

## Цель проекта

Создать полноценный, удобный и адаптивный сайт, который понятно представляет услуги, показывает выполненные работы и помогает клиентам связаться с компанией и оставить заявку.

## Планируемые возможности

- Главная страница с ясным предложением и понятной навигацией.
- Каталог услуг по автомобильному тюнингу.
- Галерея выполненных работ, по возможности с фотографиями «до/после».
- Форма заявки и удобные контакты.
- Переход в WhatsApp для связи с клиентами.
- Адаптация для компьютеров и мобильных устройств.
- В перспективе — ИИ-помощник для консультаций, ответов на вопросы и подбора услуг.

## Принципы разработки

1. Не переписывать существующее без предварительного изучения.
2. Сохранять важные изменения в Git с понятными сообщениями коммитов.
3. Перед крупными изменениями создавать отдельную ветку.
4. Проверять работу сайта на мобильном и настольном экранах.
5. Не хранить пароли, API-ключи и другие секреты в репозитории.
6. Фиксировать решения и прогресс в `PROJECT_MEMORY.md`.

## Текущее состояние

Репозиторий создан как основное хранилище проекта. На момент первоначальной настройки исходный код сайта в нём отсутствовал; сначала добавлена документация проекта. Реализацию сайта нужно вести после уточнения фактических услуг, контактных данных, фирменного стиля и структуры.

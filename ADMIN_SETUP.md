# Подключение админ-панели KarTuningKZ

## Что будет после подключения
- Администратор входит по email и паролю.
- Можно добавлять товары, менять цены, категорию и наличие, удалять позиции.
- Изменения сохраняются в общей базе данных, а не только в браузере.
- Публичный каталог сайта должен читать эту же таблицу `products`.

## 1. Создай проект Supabase
1. Создай проект на https://supabase.com/.
2. В Authentication → Users добавь только свой аккаунт администратора.
3. В Project Settings → API скопируй Project URL и anon/public key. Не используй service_role key в браузере.

## 2. Создай таблицу
Открой SQL Editor и выполни:

```sql
create table public.products (
  id bigint generated by default as identity primary key,
  created_at timestamptz not null default now(),
  name text not null,
  category text not null default 'Teyes',
  price integer not null check (price >= 0),
  old_price integer check (old_price is null or old_price >= 0),
  available boolean not null default true
);

alter table public.products enable row level security;

-- Публичные посетители могут читать каталог.
create policy "Public can read products"
on public.products for select
to anon, authenticated
using (true);

-- Изменять каталог могут только вошедшие пользователи.
create policy "Authenticated admins can insert products"
on public.products for insert
to authenticated
with check (auth.uid() is not null);

create policy "Authenticated admins can update products"
on public.products for update
to authenticated
using (auth.uid() is not null)
with check (auth.uid() is not null);

create policy "Authenticated admins can delete products"
on public.products for delete
to authenticated
using (auth.uid() is not null);
```

ВАЖНО: эти политики разрешают запись любому аутентифицированному пользователю проекта. Для единственного администратора не приглашай других пользователей; для более строгой ролевой модели позже добавим отдельную таблицу ролей и проверку admin.

## 3. Подключи ключи
Открой `admin.js` и вставь Project URL и anon/public key в константы `SUPABASE_URL` и `SUPABASE_ANON_KEY`. Публичный anon key предназначен для браузера; безопасность обеспечивают RLS-политики. Никогда не вставляй service_role key.

## 4. Опубликуй и проверь
После коммита открой `/admin.html`, войди администратором, добавь тестовый товар и поменяй цену. Удаляй тестовую запись после проверки.

## Важно про публичный каталог
Эта панель записывает товары в Supabase. Чтобы цены действительно обновлялись на витрине, главная страница и каталог должны читать таблицу `products`. Это следующий обязательный этап интеграции; одна админ-панель сама по себе не меняет старые статические карточки.
